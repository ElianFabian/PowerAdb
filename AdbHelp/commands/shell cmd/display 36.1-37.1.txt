Display manager commands:
  help
    Print this help text.

  show-notification NOTIFICATION_TYPE
    Show notification for one of the following types: on-hotplug-error, on-link-training-failure, on-cable-dp-incapable
  cancel-notifications
    Cancel notifications.
  get-brightness [--id DISPLAY_ID] [--unit UNIT]
    Gets the current brightness. Can specify the display ID, otherwise the default display is used. If no unit is specified, the returned value is in the float scale [0, 1]. The unit can be one of the following:
      percentage - return the value displayed on the brightness slider
      nits - return the brightness in nits (adjustments such as Reduce Bright Colors might be included)
  set-brightness BRIGHTNESS [--id DISPLAY_ID] [--unit UNIT]
    Sets the current brightness. Can specify the display ID, otherwise the default display is used. If no unit is specified, the value should be in the float scale [0, 1]. The unit can be one of the following:
      percentage - set the value displayed on the brightness slider
      nits - set the brightness in nits (adjustments such as Reduce Bright Colors might be included)
  reset-brightness-configuration
    Reset the brightness to its default configuration.
  ab-logging-enable
    Enable auto-brightness logging.
  ab-logging-disable
    Disable auto-brightness logging.
  dwb-logging-enable
    Enable display white-balance logging.
  dwb-logging-disable
    Disable display white-balance logging.
  dmd-logging-enable
    Enable display mode director logging.
  dmd-logging-disable
    Disable display mode director logging.
  dwb-set-cct CCT
    Sets the ambient color temperature override to CCT (use -1 to disable).
  set-user-preferred-display-mode WIDTH HEIGHT REFRESH-RATE DISPLAY_ID (optional) STORE_MODE (optional)
    Sets the user preferred display mode which has fields WIDTH, HEIGHT and REFRESH-RATE. If DISPLAY_ID is passed, the mode change is applied to displaywith id = DISPLAY_ID, if DISPLAY_ID == -1 or missing change is applied globally. If STORE_MODE is true or missing, mode will be persisted, otherwise it will beapplied without persisting. Should be used only together with DISPLAY_ID.
  reset-user-preferred-display-mode DISPLAY_ID (optional)
    Resets the user preferred display mode with stored mode. If DISPLAY_ID is passed, the persisted mode is applied to display with id = DISPLAY_ID, if DISPLAY_ID == -1 or missing persisted mode is applied globally.
    Sets the user preferred display mode which has fields WIDTH, HEIGHT and REFRESH-RATE. If DISPLAY_ID is passed, the mode change is applied to displaywith id = DISPLAY_ID, else mode change is applied globally.
  clear-user-preferred-display-mode DISPLAY_ID (optional)
    Clears the user preferred display mode. If DISPLAY_ID is passed, the mode is cleared for  display with id = DISPLAY_ID, else mode is cleared globally.
  get-user-preferred-display-mode DISPLAY_ID (optional)
    Returns the user preferred display mode or null if no mode is set by user.If DISPLAY_ID is passed, the mode for display with id = DISPLAY_ID is returned, else global display mode is returned.
  get-active-display-mode-at-start DISPLAY_ID
    Returns the display mode which was found at boot time of display with id = DISPLAY_ID
  set-match-content-frame-rate-pref PREFERENCE
    Sets the match content frame rate preference as PREFERENCE
  get-match-content-frame-rate-pref
    Returns the match content frame rate preference
  set-user-disabled-hdr-types TYPES...
    Sets the user disabled HDR types as TYPES
  get-user-disabled-hdr-types
    Returns the user disabled HDR types
  get-displays [-c|--category CATEGORY] [-i|--ids-only] [-t|--type TYPE]
    [CATEGORY]
    Returns the current displays. Can specify string category among
    DisplayManager.DISPLAY_CATEGORY_*; must use the actual string value.
    Can choose to print only the ids of the displays. Can filter by
    display types. For example, '--type external'
  dock
    Sets brightness to docked + idle screen brightness mode
  undock
    Sets brightness to active (normal) screen brightness mode
  enable-display DISPLAY_ID
    Enable the DISPLAY_ID. Only possible if this is a connected display.
  disable-display DISPLAY_ID
    Disable the DISPLAY_ID. Only possible if this is a connected display.
  power-reset DISPLAY_ID
    Turn the DISPLAY_ID power to a state the display supposed to have.
  power-off DISPLAY_ID
    Turn the display DISPLAY_ID power off.
  get-hdr-conversion-mode
    Gets the current HDR conversion mode and preferred output type.
  get-reported-hdr-types DISPLAY_ID
    Gets the HDR types supported by the current mode of the specified display.
    Returns an array of integers representing HdrCapabilities.HdrType constants
    (e.g., 1=DOLBY_VISION, 2=HDR10, 3=HLG, 4=HDR10_PLUS).
  get-supported-modes DISPLAY_ID
    Lists all supported modes (resolution and refresh rate) for the
    specified display.
  set-hdr-conversion-mode MODE [PREFERRED_TYPE]
    Sets the HDR conversion mode.
    MODE: Integer representing the HdrConversionMode.ConversionMode
      0 = UNSUPPORTED
      1 = PASSTHROUGH
      2 = SYSTEM
      3 = FORCE
    PREFERRED_TYPE: Integer representing the HdrCapabilities.HdrType
      (e.g., 0=INVALID, 1=DOLBY_VISION, 2=HDR10, 3=HLG, 4=HDR10_PLUS).
      This argument is ONLY required and used when MODE is FORCE (3).
      It MUST be a valid HDR type (not 0) in that case.
      For other modes (0, 1, 2), this argument should NOT be provided.
  get-hdr-conversion-mode
    Gets the current HDR conversion mode and preferred output type.
  get-mode-supported-hdr-types DISPLAY_ID WIDTH HEIGHT REFRESH_RATE
    Gets the HDR types supported by a specific mode (defined by WIDTH, HEIGHT,
    and REFRESH_RATE) of the specified DISPLAY_ID.
    Returns an array of integers representing HdrCapabilities.HdrType constants
    (e.g., 1=DOLBY_VISION, 2=HDR10, 3=HLG, 4=HDR10_PLUS).
  get-supported-hdr-output-types
    Gets the HDR output types globally supported by the device hardware/software.
    Returns an array of integers representing HdrCapabilities.HdrType constants
    (e.g., 1=DOLBY_VISION, 2=HDR10, 3=HLG, 4=HDR10_PLUS).
    An empty array [] may indicate no types are supported OR the feature is disabled.
  get-active-mode DISPLAY_ID
    Gets the current active display mode (resolution, refresh rate)
    for the specified DISPLAY_ID.
