Power manager (power) commands:
  help
    Print this help text.

  set-adaptive-power-saver-enabled [true|false]
    enables or disables adaptive power saver.
  set-mode MODE
    sets the power mode of the device to MODE.
    1 turns low power mode on and 0 turns low power mode off.
  set-fixed-performance-mode-enabled [true|false]
    enables or disables fixed performance mode
    note: this will affect system performance and should only be used
          during development
  suppress-ambient-display <token> [none|all|dream|aod|true|false]
    suppresses the current ambient display configuration and disables
    ambient display
  list-ambient-display-suppression-tokens
    prints the tokens used to suppress ambient display
  set-prox [list|acquire|release] (-d <display_id>)
    Acquires the proximity sensor wakelock. Wakelock is associated with
    a specific display if specified. 'list' lists wakelocks previously
    created by set-prox including their held status.
  set-wakelock [list|acquire|release] (-d <display_id>) [wakelock type]
    Acquires the specified wakelock. Wakelock is associated with
    a specific display if specified. 'list' lists wakelocks previously
    created by set-wakelock including their held status.
    Available wakelocks are described in PowerManager.*_WAKE_LOCK.
  set-face-down-detector [true|false]
    sets whether we use face down detector timeouts or not
  sleep (--disable-wakelocks) (--group-id <group ids>) 
    requests to sleep the device
      --disable-wakelocks: Force disable wakelocks before going to sleep.
        It will only act upon the wakelocks associated with the listed power groups or displays.
      --group-id <group ids>: Only sleep certain power groups, list with spaces.
      --display-id <display ids>: Only sleep power groups of listed displays, list with spaces.
      If no group ids nor display ids are specified, then default & adjacent groups will sleep.
      Usage: adb shell cmd power sleep --group-id 0 1 2 --display-id 3 --disable-wakelocks
  wakeup (<delay>) (--restore-wakelocks)
    requests to wake up the device. If a delay of milliseconds is specified,
    alarm manager will schedule a wake up after the delay.
      --group-id <group ids>: Only wake certain power groups, list with spaces.
      --display-id <display ids>: Only wake power groups of listed displays, list with spaces.
      If no group ids nor display ids are specified, then default & adjacent groups will sleep.
      --restore-wakelocks: Restore force-disabled wakelocks after wakeup.
        It will not restore wakelocks that are generically disabled.
